2. Was wir verschenken

Wir verschenken 25-mal ein Jahr Livo Plus (regulärer Preis 11,99 € inkl. MwSt.). Livo Plus endet automatisch nach einem Jahr. Es ist kein Abo, Sie müssen nichts kündigen, und es entstehen keine Kosten.

3. Zeitraum

Die Aktion beginnt mit der Veröffentlichung des Aktionsbeitrags auf unserem Instagram-Konto @heylivo.app oder unserem TikTok-Konto @heylivo. Sie endet am 30. November 2026 um 23:59 Uhr (deutsche Zeit) oder früher, sobald der Aktionscode 25-mal eingelöst wurde.

4. Wer teilnehmen kann

Teilnehmen können Personen ab 18 Jahren. Die Teilnahme ist kostenlos und hängt nicht von einem Kauf ab. Pro Person ist nur eine Einlösung erlaubt.

5. So nehmen Sie teil

Folgen Sie unserem Konto und kommentieren Sie unter dem Aktionsbeitrag das Stichwort FRIST (deutscher Beitrag) oder DEADLINE (englischer Beitrag). Auf Instagram bekommen Sie den Aktionscode dann automatisch per Direktnachricht, in der Regel innerhalb weniger Minuten. Auf TikTok schicken wir ihn Ihnen von Hand per Direktnachricht, in der Regel innerhalb von 48 Stunden.

6. Wer Livo Plus bekommt

Der Aktionscode kann insgesamt 25-mal eingelöst werden. Es zählt die Reihenfolge der Einlösung: Livo Plus erhalten die ersten 25 Personen, die den Code einlösen. Sind alle 25 Einlösungen vergeben, besteht kein Anspruch auf Livo Plus, auch wenn Sie bereits einen Code erhalten haben. Es gibt keine Verlosung.

7. Code einlösen

Öffnen Sie heylivo.com/app/?show=plus. Sichern Sie zuerst Ihr Konto mit Ihrer E-Mail-Adresse („Konto sichern“); dafür bekommen Sie einen 6-stelligen Code per E-Mail. Tippen Sie danach auf „Livo Plus kaufen“ und geben Sie im Bezahlfenster unseres Zahlungsdienstleisters Stripe den Aktionscode in das Feld für den Gutscheincode ein. Der Betrag sinkt auf 0,00 €, eine Zahlungsmethode ist nicht nötig.

Livo Plus gilt dann ein Jahr ab der Einlösung und gehört fest zu Ihrer E-Mail-Adresse. Läuft Livo Plus bei Ihnen schon, verlängert es sich um ein Jahr. Der Code ist bis zum 31. Dezember 2026 einlösbar.
